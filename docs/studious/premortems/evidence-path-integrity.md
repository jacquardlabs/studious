which token lands in which cell, where a quoted message goes, the `/coach` evidence row —
left this story and is [#249](https://github.com/jacquardlabs/studious/issues/249)'s, so

(`test_the_slug_matches_gate_ledgers_bash_branch_slug`, run over `feat/foo`,
`epic/…--…`, and a no-slash name through the real capture path).
